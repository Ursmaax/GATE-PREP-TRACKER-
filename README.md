## 🌟 What is G4Gate?

**G4Gate** is a complete, single-page study tracker built for GATE CSE and DSA
aspirants. It brings your **pomodoro timer**, **syllabus progress**, **test
analytics**, **study calendar**, **streaks**, **notes**, **doubts** and
**leaderboard** into one beautiful dark-themed dashboard.

It is **100% dependency-free on the front-end** — pure HTML, CSS and vanilla
JavaScript with zero build step — so it is blazing fast, free to host, and
easy to hack on.

| 🎯 | Purpose | Details |
|:---:|:---|:---|
| ⏱️ | **Track time** | Pomodoro focus timer with animated ring & auto session-logging |
| 📚 | **Track syllabus** | The complete GATE CSE syllabus, topic by topic with progress % |
| 📝 | **Track tests** | Log mocks, watch subject-wise averages & best scores |
| 📅 | **Track consistency** | Calendar heatmap, day streaks & an 8-week growth tree |

## 🚀 Quick Start

Run it locally in under 10 seconds:

```bash
# 1. clone the repo
git clone https://github.com/Ursmaax/GATE-PREP-TRACKER-.git
cd GATE-PREP-TRACKER-

# 2. start the server (Node 18+)
npm start          # or: node server.mjs

# 3. open your browser
open http://localhost:3000
```

That's it — no `npm install`, no build, no dependencies. 🎉

## 🌐 Deploy to Netlify

Host it **for free** with one click:

<div align="center">

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/Ursmaax/GATE-PREP-TRACKER-)

</div>

**Manual setup** — *Build command*: *(leave empty)* · *Publish directory*: **`public`**

The repo ships with everything Netlify needs:

- [`netlify.toml`](./netlify.toml) → publish directory = `public`
- [`public/_redirects`](./public/_redirects) → SPA deep-link routing (so `/plans`,
  `/timer`, `/syllabus` work on refresh)

## 🗂 Project Structure

```text
GATE-PREP-TRACKER-/
├── public/                  # the whole app (static)
│   ├── index.html           # SPA shell
│   ├── _redirects           # Netlify SPA rewrites
│   └── assets/
│       ├── app.js           # router, auth, tools, actions
│       ├── data.js          # syllabus, plans, leaders, questions
│       ├── style.css        # dark emerald/cyan design system
│       ├── favicon.svg
│       └── banner.png
├── server.mjs               # tiny Node static server (local dev)
├── netlify.toml             # Netlify build config
└── package.json             # just the `npm start` script
```
